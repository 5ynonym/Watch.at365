# Watch.at365

Windows のタスクトレイに常駐する、時計表示と入力操作補助のためのアプリケーションです。C# / .NET 10 と WPF で実装し、タスクトレイには Windows Forms、ホットキーやマウスフックには Windows API を使用しています。

## 主な機能

- **時計のオーバーレイ表示**：時刻・秒・日付・曜日を半透明で最前面に表示します。時計上のクリックは背後のウィンドウへ透過します。
- **ホットキー**：時計の表示切り替え、ディスプレイ消灯、ウィンドウ移動・最小化などを操作できます。
- **マウスジェスチャー**：ボタンやホイールの組み合わせでタブを操作し、Edge / Chrome では右ドラッグによる操作もできます。
- **クリップボードの自動消去**：5 分ごとに内容を確認し、前回と同じテキストならクリップボードを消去します。
- **自動ロック**：有効にすると、マウス操作が 6 時間ない場合に Windows をロックします。初期状態では無効です。

## ビルドと起動

開発には Windows と .NET 10 SDK が必要です。標準の発行設定は `win-x64`・ランタイム非同梱なので、発行した EXE の実行には .NET 10 Desktop Runtime（x64）が必要です。

リポジトリのルートで実行します。

```powershell
dotnet build .\Watch\Watch.csproj
dotnet run --project .\Watch\Watch.csproj
```

プロジェクトのターゲットは `net10.0-windows7.0` です。この指定だけで Windows 7 上での実行を保証するものではありません。

## 基本操作

起動すると時計とタスクトレイアイコンが表示されます。トレイアイコンの左クリック、または `Pause` で時計の表示を切り替えます。時計を非表示にしても、他の常駐機能は動作します。

右クリックメニューでは次の操作ができます。

| メニュー                       | 操作                             |
| ------------------------------ | -------------------------------- |
| `Monitor` → `0`～`3`           | 時計を表示するモニターを選択     |
| `Alignment` → `Top` / `Bottom` | 時計を画面の上端 / 下端へ配置    |
| `Toggle Watch`                 | 時計の表示・非表示を切り替え     |
| `Turn off Display`             | ディスプレイを即座に消灯         |
| `Auto Lock (6h)`               | 自動ロックの有効・無効を切り替え |
| `Exit`                         | アプリケーションを終了           |

モニター番号はプライマリを `0` とし、残りを作業領域の左座標・上座標の順で並べたアプリ独自の番号です。選択した番号のモニターが存在しない場合は `0` に表示します。

時計はローカル時刻を `HH:mm:ss`、日付を `M/d ddd`（曜日は英語の略称）で表示します。

## キーボードショートカット

「ジェスチャー中」は、後述の開始条件を満たす右ボタンまたは中央ボタンを押している状態です。その状態で別の動作が登録されているキーを押すと、通常時の代わりにその動作を実行します。

| キー                  | 通常時                                               | ジェスチャー中の別動作                                     |
| --------------------- | ---------------------------------------------------- | ---------------------------------------------------------- |
| `Pause`               | 時計の表示切り替え                                   | —                                                          |
| `Shift+Pause`         | 1 秒後にディスプレイを消灯                           | —                                                          |
| `Ctrl+Shift+Alt+M`    | ポインターをプライマリ画面の中央へ移動               | —                                                          |
| `F13`                 | エクスプローラーを開く（`Win+E`）                    | アクティブなウィンドウの実行ファイルがあるフォルダーを開く |
| `F16`                 | RDP セッションをコンソールへ切り替えるコマンドを実行 | —                                                          |
| `F17`                 | アクティブなウィンドウを最小化                       | —                                                          |
| `F18`                 | `Alt+F4` を送信                                      | —                                                          |
| `F20`                 | エクスプローラーを開く（`Win+E`）                    | ウィンドウの高さをモニターの作業領域に合わせる             |
| `Alt+Win+F10`         | ウィンドウの高さをモニターの作業領域に合わせる       | —                                                          |
| `Alt+Win+F11` / `F23` | ウィンドウを左へ移動                                 | Windows の左スナップ（`Win+←`）                            |
| `Alt+Win+F12` / `F24` | ウィンドウを右へ移動                                 | Windows の右スナップ（`Win+→`）                            |

通常時の左右移動は、現在位置に応じて中央、画面端、隣のモニターへの移動を試みます。Windows の左右スナップとは異なる動作です。

`F13`～`F24` を送信できるマウスやキーボードのマクロに割り当てることも想定しています。`Alt+Win+F1` / `Alt+Win+F4` は登録されておらず、`F14` / `F15` の割り当てもコメントアウトされています。

## マウスジェスチャー

### 開始方法と対象

右ボタンまたは中央ボタンを押したまま、別のボタン・ホイール・対応ホットキーを操作します。移動ジェスチャーは Edge / Chrome の右ボタンで開始します。

| ポインター下のアプリ                         | 通常の開始ボタン         |
| -------------------------------------------- | ------------------------ |
| Edge / Chrome（`msedge.exe` / `chrome.exe`） | 右ボタン                 |
| エクスプローラー（`explorer.exe`）           | 中央ボタン               |
| その他の除外されていないアプリ               | 右ボタンまたは中央ボタン |

- `Ctrl` を押しながら開始すると、ジェスチャーを抑止して通常のマウス操作を行えます。
- `Alt` を押しながら開始すると、除外条件を無視します。`Ctrl` と同時に押した場合も `Alt` が優先されます。
- `mstsc.exe`、`vmconnect.exe`、`taskmgr.exe`、`mmc.exe` と本アプリは、通常のジェスチャー開始対象から除外されます。
- 開始可否はポインター下のプロセスで判定し、操作の割り当ては開始時のアクティブウィンドウのプロセスで選びます。操作したいアプリを先にアクティブにしてください。
- 操作が成立しなければ、開始ボタンを離したときに通常のクリックを再送します。ただし、ブラウザーで移動方向が認識された場合は、未登録の方向列でも通常の右クリックは再送しません。

### ボタン・ホイール操作

以下は開始ボタンを押している間の**追加操作**です。通常の左クリックなどを常に置き換えるものではありません。

| 追加操作                             | 共通の動作                   | エクスプローラー / Edge / Chrome |
| ------------------------------------ | ---------------------------- | -------------------------------- |
| 左ボタンを押す                       | `Ctrl+F4`（タブを閉じる）    | 同左                             |
| 右ボタンを押す（中央ボタンで開始時） | `Ctrl+N`                     | `Ctrl+T`（新しいタブ）           |
| 中央ボタンを押す（右ボタンで開始時） | `Ctrl+N`                     | `Ctrl+T`（新しいタブ）           |
| ホイールを下へ回す                   | `Ctrl+Tab`（次のタブ）       | 同左                             |
| ホイールを上へ回す                   | `Ctrl+Shift+Tab`（前のタブ） | 同左                             |

送信したキーの実際の動作は、対象アプリ側の対応に依存します。

### 移動ジェスチャー（Edge / Chrome）

右ボタンを押しながらポインターを動かし、ボタンを離すと実行します。方向は各判定基準点から 50 ピクセルを超える移動で認識し、認識中は方向とアクション名を表示します。

| 方向 | 動作                                        |
| ---- | ------------------------------------------- |
| ↑    | 閉じたタブを復元（`Ctrl+Shift+T`）          |
| ↑↓   | 全画面表示の切り替え（`F11`）               |
| ↓    | キャッシュを無視して再読み込み（`Ctrl+F5`） |
| →    | 進む（`Alt+→`）                             |
| ←    | 戻る（`Alt+←`）                             |

エクスプローラーの移動ジェスチャーは現在登録されていません。

## クリップボードの自動消去

この機能は起動時から動作し、切り替え用のメニューはありません。履歴の保存・復元機能は実装されていません。

5 分間隔で `DataFormats.Text` を読み取り、前回の確認時と同じ文字列なら、クリップボード全体を消去します。コピー時刻を直接監視しているわけではなく、同じ文字列をコピーし直しても消去対象になります。

テキストを取得できない画像・ファイルなどは `null` として比較されるため、それらも消去される場合があります。

## 自動ロックと設定

`Auto Lock (6h)` を有効にすると、マウスの移動・クリック・ホイール操作がない時間を計測し、6 時間以上になった時点で Windows をロックします。確認間隔は 1 分です。**キーボード入力は計測対象に含まれません。** 起動時と有効・無効の切り替え時には計測をリセットします。

以下の設定は `%APPDATA%\at365\Watch\config.json` に保存され、次回起動時にも使用されます。フォルダーとファイルは初回起動時に作成され、トレイメニューで変更した時点で保存されます。

| 設定         | 初期値       |
| ------------ | ------------ |
| 時計の表示先 | モニター `0` |
| 時計の配置   | `Top`        |
| 時計の表示   | 表示         |
| 自動ロック   | 無効         |

ジェスチャーの除外対象も同じファイルの `Blacklist` に保存します。設定ファイルの例は以下のとおりです。`Alignment` は `0` が上端、`2` が下端です。

```json
{
  "Monitor": 0,
  "Alignment": 0,
  "Visible": true,
  "AutoLockEnabled": false,
  "Blacklist": ["example.exe", "another-app.exe"]
}
```

手動編集する場合はアプリを終了してから変更し、再起動してください。`Blacklist` は実行ファイル名を指定し、大文字・小文字は区別しません。

`config.json` がない場合だけ、従来のユーザー設定と EXE と同じフォルダーの `blacklist.json` を読み込んで移行します。旧ファイルは変更せず、以後の保存・復元には `config.json` を使います。移行元がなければ上記の初期値（`Blacklist` は空配列）で開始します。

JSONが壊れている場合は `config.json.invalid-...` に退避コピーを試み、初期値で起動します。読み込みに失敗した元ファイルはその時点では上書きしません。保存は一時ファイルを書き終えてから置き換える方式で、失敗は診断ログに記録します。

ブラックリスト切り替え処理はありますが、現在は呼び出し用のホットキーが登録されていません。キー・ジェスチャーの割り当て変更は [GestureModule.cs](Watch/Gesture/GestureModule.cs)、時計の見た目の変更は [Watch.xaml](Watch/Watch.xaml) を編集して再ビルドします。

## 発行と配置

リポジトリのルートで実行します。

```powershell
.\publish.bat
.\deploy.bat "C:\Tools\Watch.at365"
```

[publish.bat](publish.bat) は Release / `win-x64` の単一実行ファイルを `publish\Watch.at365.exe` に生成します。.NET ランタイムは同梱しません。追加の `dotnet publish` オプションを引数で渡せますが、出力先や単一ファイル設定を変更した場合は配置方法も調整してください。

[deploy.bat](deploy.bat) は発行済みの EXE だけを配置先へ上書きコピーします。配置先フォルダーを事前に作成し、実行中のアプリをトレイメニューの `Exit` で終了してから実行してください。発行・フォルダー作成・アプリの終了・起動は自動では行いません。

引数なしで配置する場合は、[deploy.local.txt.example](deploy.local.txt.example) を `deploy.local.txt` にコピーし、1 行目に配置先の絶対パスを引用符なしで記入します。引数がある場合はそちらを優先します。`deploy.local.txt` は Git 管理対象外です。

## 実装上の留意点

- 起動時に同名の既存プロセスを終了させる実装です。二重起動すると既存のインスタンスが置き換わります。
- ディスプレイ構成の変更通知（`WM_DISPLAYCHANGE`）を受けると、アプリの再起動を試みます。
- マニフェストは `highestAvailable` を指定しています。アカウントによって起動時に昇格を求められます。対象アプリの権限や入力制限により、キー送信やウィンドウ操作が効かない場合があります。
- 他のアプリとの競合などでホットキー登録に失敗しても、エラー表示は行いません。失敗は下記の診断ログに記録します。
- `F16` は `tscon rdp-tcp#0 /dest:console` を実行する固定の実装です。セッション名や権限が合わない環境では動作しません。

## 診断と回帰テスト

起動、ホットキー、ジェスチャー、クリップボード、自動ロックなどの失敗は `%APPDATA%\at365\Watch\errors.log`（通常は `AppData\Roaming\at365\Watch\errors.log`）に記録します。ログには処理名・例外の種類・エラーコードのみを記録し、クリップボード本文は保存しません。約 1 MiB を超えると `errors.log.old` に世代交代します。

自動ロックが無効の間は、専用のマウスフックと確認タイマーを停止します。マウスのみを対象に 6 時間を計測する仕様は変わりません。時計の変更に影響されない経過時間で計測します。

Windows / .NET 10 SDK 上で、追加のテストパッケージを必要としない回帰テストを実行できます。

```powershell
dotnet run --project .\Watch.RegressionTests\Watch.RegressionTests.csproj
```

このテストは常駐アプリを起動せず、実際のクリップボード消去・入力送信・プロセス強制終了・画面ロックも行いません。クリップボードの既存仕様、モジュールの解放、ジェスチャーの状態遷移、遅延処理、入力イベント列を検証します。失敗時は終了コード `1` を返します。

レビュー内容と実機確認が必要な項目は [REVIEW.md](REVIEW.md) を参照してください。
