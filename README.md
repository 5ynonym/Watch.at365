# Watch.at365 - システム生産性向上ツール

**Watch.at365** は .NET 10 で開発された Windows デスクトップアプリケーションです。高度なシステムジェスチャ、クリップボード管理、キーボード・マウス自動化機能を提供し、ホットキーやマウスジェスチャ、ウィンドウ操作のショートカットで生産性を向上させます。

## 特徴

### 時計表示
- Haettenschweiler のフォントを使用した大きな時計表示 
 - フォントは別途インストールが必要 https://www.google.com/search?q=Haettenschweiler

### 🎮 ジェスチャ管理
- **キーボードジェスチャ**: 修飾キーを組み合わせたカスタムホットキー
- **マウスボタンジェスチャ**: アプリケーションごとに異なるマウスボタン操作
- **マウスムーブジェスチャ**: 方向（右・左・上・下）へのマウス移動でコマンド実行

### ⌨️ ホットキーシステム
- F13～F24ファンクションキーや修飾キー（Alt, Windows, Ctrl, Shift）対応
- アプリケーションごとに異なるジェスチャ設定
  - **エクスプローラー**: タブ管理やナビゲーション
  - **Webブラウザ** (Edge, Chrome): タブ操作、ページ移動、リロード
  - **システム全体**: ウィンドウ管理、プロセス操作

### 🪟 ウィンドウ管理
- ウィンドウの左右移動・スナップ
- ウィンドウの高さを全画面に調整
- 最小化・最大化・プロセス情報取得
- 実行中プロセスのフォルダを開く

### 📋 クリップボード管理
- クリップボード操作や履歴管理

### 🔒 自動ロック
- マウスが6時間操作されない場合、自動的に Windows をロック
- タスクトレイのコンテキストメニューから「Auto Lock (6h)」で有効/無効を切替（チェックマークで現在の状態を表示）
- 設定はユーザー設定として永続化

### 🔧 Windowsネイティブ連携
- 低レベルマウスフックによるジェスチャ検出
- Windows APIを利用したシステム操作
- DPI対応ウィンドウ描画
- リモートデスクトップ（RDP）対応

## ジェスチャー

### キーボードジェスチャ

| キー | アクション |
|------|--------|
| `Pause` | 時計表示のON/OFF切替 |
| `Shift+Pause` | 1秒後にディスプレイをオフにする |
| `Ctrl+Shift+Alt+M` | カーソルを画面中央へ移動 |
| `Alt+Win+F1` / `F13` | 実行中プロセスのフォルダを開く |
| `Alt+Win+F4` / `F16` | RDPからコンソールセッションに復帰 |
| `F17` | アクティブウィンドウを最小化 |
| `F18` | Alt+F4（ウィンドウを閉じる） |
| `F20` | エクスプローラーを開く |
| `Alt+Win+F10` | ウィンドウを全高に調整 |
| `Alt+Win+F11` / `F23` | ウィンドウを左へスナップ |
| `Alt+Win+F12` / `F24` | ウィンドウを右へスナップ |

### マウスボタンジェスチャ

#### 全体
| トリガー | アクション |
|---------|--------|
| 左ボタンダウン | ブラウザタブを閉じる |
| 右ボタンダウン | Ctrl+N（新規） |
| 中央ボタンダウン | Ctrl+N（新規） |
| ホイールダウン | 次のタブ |
| ホイールアップ | 前のタブ |

#### エクスプローラー
| トリガー | アクション |
|---------|--------|
| 右ボタンダウン | 新しいタブ |
| 中央ボタンダウン | 新しいタブ |

#### Webブラウザ（Edge, Chrome）
| トリガー | アクション |
|---------|--------|
| 右ボタンダウン | 新しいタブ |
| 中央ボタンダウン | 新しいタブ |

### マウスムーブジェスチャ

#### エクスプローラー
| ジェスチャ | アクション |
|---------|--------|
| →（右） | 進む |
| ←（左） | 戻る |
| ↑（上） | 1階層上へ |

#### Webブラウザ
| ジェスチャ | アクション |
|---------|--------|
| ↑（上） | 閉じたタブを復元 |
| ↑↓（上→下） | フルスクリーン切替（F11） |
| ↓（下） | ページをリロード |
| →（右） | 進む |

## 注意事項
- 一部機能は管理者権限が必要です（低レベルフック、ウィンドウ操作等）
- RDP（リモートデスクトップ）固有機能はRDPコンソールアクセスが必要です
- UAC保護ウィンドウ等ではマウスジェスチャが動作しない場合があります
- ジェスチャ検出は20ms間隔でスロットリングしています

## 発行と配置

.NET 10 SDK を使用して、リポジトリのルートで実行します。

```powershell
.\publish.bat
.\deploy.bat "C:\Tools\Watch.at365"
```

[publish.bat](publish.bat) は Release・win-x64 の単一実行ファイルを `publish\Watch.at365.exe` に生成します。実行先には .NET 10 Desktop Runtime（x64）が必要です。追加の dotnet オプションも渡せますが、出力先や単一ファイル設定を変更した場合は配置方法も調整してください。

[deploy.bat](deploy.bat) の配置先は引数が優先されます。引数なしで使う場合は、[deploy.local.txt.example](deploy.local.txt.example) を `deploy.local.txt` にコピーし、1行目に配置先の絶対パスを引用符なしで記入してください。このローカル設定は Git 管理対象外です。

配置先フォルダーは事前に作成し、実行中のアプリを終了してから配置してください。バッチは EXE を上書きします。アプリの強制終了や自動起動は行いません。
